Retrieval scheduling

First transmission time is when the latest DCP transmission should already be available on LRGS. The automatic scheduler decides whether a DCP is due; Pull Now bypasses that waiting period.

Run History distinguishes queued, completed, partial, and failed retrievals. A DCP's legacy last_datetime remains its most recent scheduled attempt.
