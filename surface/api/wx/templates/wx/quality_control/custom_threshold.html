How copying works

You can only copy thresholds between stations of the same type (Automatic or Manual).

Only variables shared by both stations will be copied. For example, if Station A has Air Temperature, Precipitation and Wind Speed, but Station B only supports Air Temperature and Precipitation, only those two shared variables will be copied.

Range: All existing monthly custom thresholds from the source station will be copied. Months without source thresholds will remain unchanged at the destination.

Step and Persist: Existing source custom thresholds will be copied for shared variables.

Global thresholds and reference-station assignments will not be modified.

Existing destination custom thresholds will be overwritten where the source station has matching records. Destination-only records will remain unchanged. Cancel Copy [[ snackbarText ]]
